ASUS ProArt P14 with NVIDIA RTX Spark: An AI-Powered Creator Laptop

We test the new NVIDIA new RTX Spark for mobile platform. That means it combines an Arm-based CPU, a Blackwell GPU and a large shared memory pool in one system-on-chip. That approach differs from a conventional laptop with a separate processor, discrete graphics card and dedicated video memory. The ASUS ProArt P14 is designed to bring local AI and GPU-accelerated creative work into a more portable system, while retaining the Windows environment used for everyday productivity. NVIDIA Spark began with the DGX Spark, a compact desktop system built around the GB10 Grace Blackwell Superchip. It was designed to let developers run AI models locally, using a large unified memory pool shared by the CPU and GPU. RTX Spark takes that concept into Windows laptops and mini PCs. With ASUS’s ProArt P14, the platform is aimed at mobile creators and professionals who want local AI capability in a laptop they can carry between workspaces. The shared memory subsystem is one of RTX Spark’s defining features. In a conventional laptop, system memory serves the CPU, while a discrete GPU usually has its own dedicated video memory. With a unified pool, the CPU and GPU can access the same memory, which can reduce data transfers between separate memory spaces. This matters for AI models and creative projects that involve large datasets, high-resolution media, or complex scenes. Capacity is central to the design. A larger shared pool can allow compatible AI workloads to load models that would exceed the dedicated VRAM available on many mobile GPUs. It can also give applications more room for project data and intermediate results. The memory is shared across the system, however, so the full capacity is not reserved for the GPU alone. Results will depend on memory bandwidth, software support, and how a particular workload divides its data between CPU and GPU. For local AI, this design could be useful when model size is the first limitation. Users can experiment with inference, image generation, or other AI tasks on the laptop itself, without relying on a remote service for every operation. It may also help with workflows that move between CPU and GPU processing, since both can access the same pool. The practical advantage will vary by application, so our testing looks at how the P14 handles supported workloads rather than treating memory capacity as a performance guarantee.

Arm CPU and NVIDIA Blackwell GPU

RTX Spark uses Arm CPU cores instead of the x86 processors typically found in AMD- and Intel-based Windows laptops. The N1X family combines performance cores for demanding tasks with efficiency cores for lighter work and background activity. The CPU is responsible for general application processing, operating-system tasks, and workloads that do not benefit from GPU acceleration. Graphics and parallel compute are handled by NVIDIA’s Blackwell GPU cores. These can accelerate supported creative applications and AI software, as well as render graphics. The CPU and GPU are integrated into the same platform and can use the shared memory subsystem.



For a creator, that combination could be particularly relevant when an application uses both general-purpose processing and GPU acceleration on large assets. Software compatibility remains an important part of the experience. Applications built or optimized for Arm and RTX Spark can run natively, while some existing Windows software may need emulation. Support for NVIDIA GPU acceleration also differs between applications and individual features. That means a workload’s real performance depends not only on the hardware but also on whether the software has been adapted to use it. The ProArt P14 is aimed at people who need a mobile system for creative and AI-assisted work. Potential workflows include photo editing, video production, 3D work, and GPU-accelerated effects, alongside local AI inference and model experimentation. A developer could use it to prototype an AI application or test a model away from a desktop workstation. A creator might use local tools to process material while travelling or working with limited connectivity. Local processing can also be useful when a workflow involves sensitive files or when internet access is unreliable. It gives users the option to keep more of the work on the device, although privacy still depends on the software and services they choose to use. The P14’s suitability will depend on the applications in a user’s daily workflow. Those relying on specialized x86 software should verify compatibility, and anyone choosing the laptop primarily for gaming or maximum conventional CPU performance should compare it with more traditional laptop platforms. RTX Spark’s distinguishing proposition is its combination of Arm CPU cores, Blackwell GPU cores, and a large shared memory subsystem.
